# DormFix System Context

## X.C.1 Student Resident

Direction: In / Out

Information entering DormFix:
- Maintenance issue description
- Location information
- Access availability
- Missing information responses
- Repair resolution confirmation

Information leaving DormFix:
- Missing-information prompts
- Structured maintenance request
- Ticket status
- Repair completion information

## X.C.2 Property Manager

Direction: In / Out

Information entering DormFix:
- Priority decisions
- Technician assignment decisions

Information leaving DormFix:
- Submitted maintenance requests
- Structured ticket information
- Outstanding-work status

## X.C.3 Maintenance Technician

Direction: In / Out

Information entering DormFix:
- Repair progress updates
- Completion status
- Repair notes

Information leaving DormFix:
- Assigned maintenance requests
- Issue details
- Location and access information

## X.C.4 Housing Administration

Role: External oversight stakeholder

Housing Administration does not directly participate in the nominal maintenance-request workflow. It has an interest in maintenance performance, unresolved work, and the traceability of maintenance records.
