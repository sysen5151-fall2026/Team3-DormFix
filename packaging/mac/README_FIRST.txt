DormFix macOS Quick Start
=========================

1. Python 3.10+ required.
2. Double-click: Install DormFix.command
3. If Apple cannot verify it: System Settings -> Privacy & Security -> Security -> Open Anyway.
4. Confirm with Touch ID/password, then Open.
5. After installation, double-click: ~/Applications/DormFix.app
6. Browser: http://127.0.0.1:8502

Do not disable Gatekeeper globally. Full guide: README.md / MAC_INSTALL_GUIDE.md
